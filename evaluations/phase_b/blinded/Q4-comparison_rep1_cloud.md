# PostgreSQL and SQLite: Concurrency, Deployment, and Use Cases

## Summary

PostgreSQL uses MVCC and row-level locking, allowing many transactions to write to different rows simultaneously without blocking each other. [S2] PostgreSQL runs as its own server process, listens on a network port, and accepts connections from applications acting as clients. [S2]

## Deployment

SQLite is a library that runs inside the application process and reads from a single database file, with no server, port, or users to configure. [S2]
