# PostgreSQL vs SQLite: Concurrency, Deployment, and Use Cases

## Summary

SQLite is a C library embedded directly in the application process with no server component. [S3] PostgreSQL uses multi-version concurrency control (MVCC) and row-level locking to allow concurrent writes to different rows. [S2] SQLite is suitable for embedded applications, local tools, mobile apps, desktop software, and development environments. [S3] PostgreSQL is suitable for web applications, APIs, and systems with concurrent network access. [S3]
