# Overview of Retrieval-Augmented Generation

## Summary

Retrieval-Augmented Generation (RAG) is a framework that augments large language models with external knowledge access via document retrieval. [S1] RAG enables large language models to retrieve and incorporate new information from external data sources. [S5]

## Core Technical Mechanism

RAG operates with retrieval and pre-processing steps to enhance generative AI outputs. [S2]

## Accuracy Improvements

RAG systems offer greater transparency, factual grounding, and adaptability to evolving knowledge bases. [S1]

## Key Limitations

Misalignment between retrieved evidence and generated text can lead to hallucinations. [S1]

Pipeline inefficiencies and latency increase deployment costs at scale. [S1]

## Real-World Use Cases

RAG has been studied in healthcare for grounding LLM outputs in medical knowledge sources. [S5]
