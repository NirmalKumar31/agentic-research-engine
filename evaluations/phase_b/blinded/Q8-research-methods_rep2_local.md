# Overview of Evaluation Metrics for Retrieval Quality in RAG Systems

## Summary

Context precision measures the percentage of retrieved documents that are actually relevant to the query. [S3] Context recall measures whether the retrieval captured all the relevant documents available in the knowledge base. [S3] Retrieval ranking metrics such as NDCG@K and Precision@K evaluate whether the most relevant documents appear at the top of the results. [S3] Faithfulness score calculates the ratio of supported claims to total claims in the answer. [S3] Answer relevancy checks whether the response addresses the user's question rather than discussing tangential topics. [S3] Answer similarity compares generated responses against reference answers using semantic similarity when known correct answers exist. [S3]

## Commonly Used Evaluation Metrics

Five key metrics are used to evaluate RAG performance: context relevance, context sufficiency, answer relevance, answer correctness, and answer hallucination. [S2]

## Limitations in Real-World Deployments

Traditional retrieval metrics like recall and precision cannot fully capture the nuances of RAG systems. [S1]
