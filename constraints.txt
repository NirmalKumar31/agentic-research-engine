# Pinned runtime dependency set for reproducible deployment builds.
#
# Scope: the runtime and web closure only -- exactly `pip install ".[web]"`
# and nothing else. This is what Dockerfile.web builds against, so anything
# in here ships to the deployed service.
#
# It is generated from a clean virtual environment, never from a developer
# machine. A previous version was produced with `pip freeze` against a
# working environment and pinned the entire Streamlit ecosystem, pytest,
# mypy, ruff and pip-audit into the deployment image -- while omitting
# fastapi, which the web extra actually needs.
#
# pyproject.toml keeps deliberately broad ranges because this is installed
# as a library. This file pins what a *build* uses, so a container image is
# reproducible and a transitive update cannot silently change behaviour
# between deploys. Application installs are unaffected unless you ask:
#     pip install -e . -c constraints.txt
#
# Regenerate in a clean environment:
#     python -m venv /tmp/fresh
#     /tmp/fresh/bin/pip install ".[web]"
#     /tmp/fresh/bin/pip freeze --exclude-editable \
#       | grep -v '^agentic-research-engine' | sort > constraints.txt
#
